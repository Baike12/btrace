## Security Policy

btrace is a fork of [Langfuse](https://github.com/langfuse/langfuse) with a PostgreSQL-only
storage layer and a Rust backend. It is maintained as a separate project, so report issues
found in this deployment or in the fork-specific code through this repository's own
channels rather than upstream's.

For vulnerabilities that also affect upstream Langfuse, see the
[Langfuse security policy](https://github.com/langfuse/langfuse/security/policy).
